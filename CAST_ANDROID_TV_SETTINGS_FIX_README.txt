NOVA AI - CAST AND SETTINGS FULL FIX

This version keeps old functions intact and adds:
- Cast laptop to Android TV
- Open Windows Cast panel using Win+K
- Duplicate/mirror/extend/second-screen projection commands
- Stop casting / PC screen only command
- All Windows settings control dashboard
- More direct settings pages: display, sound, Wi-Fi, Bluetooth, microphone, camera, apps, storage, battery, power, notifications, date/time, language, accounts, taskbar, update, VPN, proxy, troubleshoot, recovery, about

Run:
python nova_ai_ultimate.py --web

Try commands:
cast my laptop to android tv
screen mirror to android tv
duplicate screen
extend screen
stop casting
open all settings
control all settings
open display settings
open sound settings
open microphone settings
open bluetooth settings

Note: Android TV and laptop must be on the same Wi-Fi. TV may ask Allow/Pair on remote. Nova cannot bypass pairing, Wi-Fi, or TV permission prompts.
