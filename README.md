# AI Assistant (Nova Ultimate)

A sophisticated desktop AI assistant designed for extensive system automation, app routing, and smart PC management.

## 🌟 Key Features
- **Application Automation**: Intelligently opens and controls local applications.
- **System Settings Management**: Can directly toggle system settings like Wi-Fi, Bluetooth, Audio, and more.
- **Voice & Speech**: Complete offline text-to-speech handling with multiple language support (English/Hindi).
- **Network & Mobile Mode**: Includes specialized configurations for casting and mobile routing.
- **Self-Repair & Diagnosis**: Includes batch scripts for automatically fixing audio, Windows tools, and network configurations.

## 🚀 Getting Started

### 1. Initial Setup
Run the main startup script:
```bash
START_HERE.cmd
```

### 2. Required Fixes (If Needed)
If you experience any issues, the project includes several automatic installers and fixers:
- `INSTALL_AUDIO_FIX.cmd`: Fixes Windows audio recognition issues.
- `INSTALL_HINDI_VOICE.cmd`: Sets up Hindi text-to-speech.
- `ALLOW_NOVA_NETWORK.cmd`: Automatically configures Windows Firewall to allow Nova's network features.

## 📝 Usage Notes
Review the included `README_START_HERE.txt` and various `*_FIX_README.txt` files for detailed explanations on each individual component and how to configure them for your specific PC environment.
