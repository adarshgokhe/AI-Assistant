Nova AI Think-And-Control Fix

IMPORTANT FIRST STEP:
1. Run START_HERE.cmd or run: python nova_ai_ultimate.py
2. In Nova command box, type: learn laptop
3. Then use commands like:
   open my asus
   open settings
   open bluetooth settings
   play jhol song in spotify
   search dishant in whatsapp
   close whatsapp
   make word file with date and time code
   mujhe aaj ki date aur time batao

Online smart chat:
- Copy .env.example to .env
- Add GEMINI_API_KEY=your_new_key_here

Notes:
- Nova will NOT search Google unless you say search/google.
- Spotify play depends on Spotify desktop being installed and logged in. Nova can open/search and tries Enter/Space, but Spotify may require manual login/permissions.
- WhatsApp contact search depends on WhatsApp Desktop/Web being logged in.
- Direct Wi-Fi/Bluetooth changes may need Administrator permission. Nova opens the exact settings page if Windows blocks direct change.
